# 🦉 Portfolio Quentin Beaud (Edsaje / Hibouxe)

Bienvenue sur le dépôt de mon portfolio personnel !
Ce site a été conçu pour refléter ma double identité : **Concepteur Développeur Fullstack Java / C#** (Quentin Beaud) et **Créateur de Contenu / Lore Analyst** (Hibouxe).

Le projet a été développé intégralement en **Vanilla JavaScript, HTML5 et CSS3**, sans aucun framework ni dépendance tierce, avec un accent particulier sur la légèreté, l'ambiance visuelle et plusieurs mini-jeux / easter eggs cachés.

🌍 **Site en ligne :** [quentinbeaud.com](https://www.quentinbeaud.com/)

---

## ✨ Points clés

* 🎨 **Thème & Ambiance :** Esthétique sombre inspirée de *La Forêt du Hibou* (noir profond, vert mousse, accents dorés `#d4af37`), avec arrière-plan animé de lucioles en Canvas.
* 📱 **Mobile-First & Responsive :** Interface adaptée aussi bien aux mobiles (avec manette tactile virtuelle pour les jeux) qu'aux écrans de bureau.
* 📜 **CV en double format :** Version interactive intégrée au site et version PDF prête à l'impression.
* ⚡ **Zéro dépendance :** Pas de framework lourd ni de build npm, tout s'exécute directement dans le navigateur.

---

## 🎮 Easter Eggs & Mini-Jeux

Derrière la vitrine de présentation se cachent plusieurs moteurs de jeux codés en pur JavaScript et Canvas 2D :

### 🕹️ 1. La Salle d'Arcade Secrète (7 jeux rétro)
* **Comment y accéder :** Taper `A-R-C-A-D-E` au clavier ou tapoter **3 fois rapidement** sur le petit hibou dans le pied de page.
* **Les jeux :** Snake Doré, Pong Magique, Casse-Briques, Flappy Hibou, Hibou Invaders, Forest Run et Tetris Mystique.
* **Support mobile :** Une manette virtuelle avec D-Pad et bouton d'action s'affiche automatiquement sur smartphone.

### ⚡ 2. Émulateur Vectrex (Mine Storm 1982)
* **Comment y accéder :** Taper `V-E-C-T-R-E-X` au clavier ou cliquer 3 fois sur l'indice Vectrex dans la section Vidéos.
* **Le jeu :** Un hommage au classique vectoriel *Mine Storm* de la console Vectrex (1982), avec rendu de lignes lumineuses sur fond noir.

### 🪶 3. Hibou Clicker (Jeu incrémental)
* **Comment y accéder :** Icône flottante sur la gauche de l'écran.
* **Mécaniques :** Production automatique de plumes, multiplicateurs de paliers, système de prestige céleste, succès déblocables et sauvegarde dans le `localStorage`.

## 🛠️ Stack Technique

* **HTML5** : Sémantique, SEO, métadonnées OpenGraph et données structurées Schema.org.
* **CSS3** : Variables CSS, Flexbox, CSS Grid, Glassmorphism et animations.
* **JavaScript ES6+** : Canvas 2D, gestion audio, boucle `requestAnimationFrame`, persistance `localStorage`.
